# IT Service Management (ITSM) System
## Project Overview
This project focuses on developing an IT Service Management (ITSM) system to efficiently manage IT services, incidents, and service requests within an organization. The system aims to streamline IT operations, improve response time, and enhance user satisfaction.
##  Problem Statement
Organizations often face challenges in handling IT incidents, service requests, and tracking issues efficiently. Manual processes lead to delays and lack of transparency. This project provides a structured solution to automate and manage IT services effectively.
## Project  Approach
This project is designed to:
- Classify high priority tickets 
- Forecast Incident/Ticket volume
- Auto tag tickets 
- Predict request for change  
## Key Features
- High Priotiry Tickets  
- Forecast Incident/Ticket volume  
- Ticket Assignment & Tracking  
- Status Monitoring (Open, In Progress, Closed)  
- Basic Reporting and Insights  
## Technologies Used
- Python  
- Pandas / NumPy  
- Matplotlib,seaborn
- Mulitple ML Models & Advance ML Models like(XGBoost, LightGBM)
- Used SMOTE for imbalanced data
- Preprocessing techniques like Encoding,Feature Engineering, Missing values,Outlier Detection
- Model Evaluation
- Colab Notebook  
## Workflow
1.Find the High Priority Tickets
2. Forecast the Ticket/Incident Volume
3. Auto tag the Ticket by department /Priority
4. Predict Request for change (RFC)
## Outcomes
- Improved tracking of IT incidents  
- Faster resolution time  
- Better organization of service requests  
- Enhanced visibility of IT operations  
## Business Impact
- Reduces downtime and operational delays  
- Improves efficiency of IT support teams  
- Enhances user satisfaction with faster issue resolution  
- Provides structured IT service workflows
