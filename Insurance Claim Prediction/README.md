## Project Overview
Insurance companies face uncertainty due to varying customer risk profiles and unpredictable claim behavior. This project uses Machine Learning techniques to predict insurance claim likelihood and/or claim payment amount based on anonymized customer data.
The goal is to help insurers make better financial and risk management decisions.
## Problem Statement
- Build a predictive model to estimate insurance claim behavior.
- Compare multiple machine learning models.
- Recommend the best model for production use.
- Analyze challenges faced during model development.
## Domain
Finance – Insurance Analytics
## Dataset Information
- Records: 595,212
- Features: 59 (anonymized)
- Data Type: Customer and risk-related attributes
- Source: Provided dataset (privacy-protected)
